# Computer Vision

This repository contains a collection of Computer Vision projects and experiments developed using Python, OpenCV, and MediaPipe.

The projects focus on practical Computer Vision applications such as face detection, facial expression detection, smile detection, face landmarks, hand tracking, and real-time camera-based applications.

## Technologies Used

* Python
* OpenCV
* MediaPipe
* NumPy
* Haar Cascade Classifiers

## Projects

Some of the projects included in this repository are:

* Face Detection
* Facial Expression Detection
* Smile Detection
* Eye Detection
* Face Landmark Detection
* Hand Detection and Tracking
* Real-Time Face Tracking
* Image Processing
* Video Processing
* Other OpenCV and MediaPipe-based projects

More projects will be added as I continue exploring Computer Vision.
